### Added
- Caveman Code joins Settings → Agents, the setup guide and the agent pickers: Ovis installs it with
  `npm install -g @juliusbrussee/caveman-code` and starts `caveman-code` in the pane's shell. With the
  web UI's Caveman Code extension (`bun scripts/install-caveman-integration.ts`), herdr shows its pane
  as an agent with its status, reopens its session after a herdr restart, and the chat reads its
  session on Linux.
